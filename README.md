# 🩺 HealthLens – Medical Question Answering Assistant

HealthLens is a domain-specific Medical Question Answering (QA) system built using **Generative AI, QLoRA fine-tuning, Retrieval-Augmented Generation (RAG), and safety guardrails**. 
The project aims to provide medically grounded responses while minimizing hallucinations and unsafe advice commonly generated by general-purpose language models.

## 🚀 Features

* Fine-tuned **Microsoft Phi-2 (2.7B)** using **QLoRA**
* **FAISS-based RAG pipeline** for retrieval of relevant medical context
* Input and output **safety guardrails**
* Medical question-answering on verified clinical datasets
* Interactive **Streamlit UI**
* Evaluation using **ROUGE, BLEU, and BERTScore**

---

## 🏗️ Architecture

```text
User Query
    ↓
Input Guardrail
    ↓
FAISS Retrieval (RAG)
    ↓
Context-Augmented Prompt
    ↓
QLoRA Fine-Tuned Phi-2
    ↓
Output Guardrail
    ↓
Response
```

## 🔍 Retrieval-Augmented Generation (RAG)

HealthLens uses:

* **Sentence Transformers:** `all-MiniLM-L6-v2`
* **Vector Database:** FAISS
* **Top-K Retrieval:** 2

Retrieved clinical context is injected into prompts before generation to improve factual grounding and reduce hallucinations.

---

## 🛡️ Safety Guardrails

### Input Guardrail

Blocks unsafe queries such as:

* Dosage recommendations
* Self-diagnosis requests
* Prescription requests
* Emergency medical assessments

### Output Guardrail

Flags generated responses containing:

* Dosage instructions
* Pill-count recommendations
* Absolute safety claims
* Guaranteed outcomes
